# Конвертер форматов для Windows — план проекта (v2)

Название: **Morphio**.
Платформа: **только Windows 10 (22H2) / Windows 11, x64**. Мак, Linux, веб и мобильные версии не делаем, это упрощает всё: стек, установщик, тестирование.

---

## 1. Идея

Один локальный инструмент вместо десятка сайтов-конвертеров.

- **Конвертер** для всех популярных форматов.
- **Удаление фона** с изображений (нейросеть, офлайн).
- **GIF-студия**: GIF/WebP/APNG из картинок и видео.
- **Всё офлайн**: файлы не покидают компьютер, нет лимитов, рекламы, капч и водяных знаков.

### Чем лучше аналогов
| Проблема сайтов и приложений | Наше решение |
|---|---|
| Загрузка файлов на чужой сервер | Всё локально |
| Лимиты, подписки, водяные знаки | Без лимитов |
| Нужно знать формат и битрейт | Режим "по цели" (Telegram, сайт, печать) |
| Не угадать размер результата | Целевой размер файла + предпросмотр до/после |
| Разрозненные инструменты | Всё в одном + цепочки действий |
| Медленно | Ускорение на видеокарте (NVENC / Quick Sync / AMF, DirectML) |

## 2. Ключевые функции

### 2.1 Конвертер
| Категория | Форматы | Движок |
|---|---|---|
| Изображения | PNG, JPG, WebP, AVIF, HEIC, BMP, TIFF, SVG, ICO, PSD (чтение) | libvips (sharp), ImageMagick |
| Видео | MP4, MKV, MOV, WebM, AVI, GIF | FFmpeg |
| Аудио | MP3, WAV, FLAC, OGG, AAC, M4A | FFmpeg |
| Документы | DOCX, PDF, ODT, RTF, TXT, MD, HTML | Pandoc (+ LibreOffice как необязательный модуль) |
| Данные | XLSX, CSV, JSON, XML, YAML | свои парсеры |
| Книги | EPUB, FB2, MOBI | Pandoc / Calibre-модуль |
| Архивы | ZIP, 7z, TAR (RAR только чтение) | 7-Zip |
| Субтитры, шрифты | SRT/VTT/ASS, TTF/OTF/WOFF2 | свои парсеры, fonttools |

Общее: пакетная обработка, очередь с паузой и прогрессом, пресеты, сохранение или очистка метаданных (GPS и др.).

### 2.2 Режим "по цели"
Пользователь выбирает не формат, а задачу: "Telegram", "Instagram", "для сайта", "для печати", "для почты". Приложение подбирает формат, размер и качество.

### 2.3 Целевой размер файла
"Не больше 8 МБ": автоматический подбор качества (поиск по битрейту/качеству) для видео, изображений, GIF, PDF.

### 2.4 Сравнение до/после
Слайдер до/после, размер файла, метрика потери качества (SSIM/PSNR).

### 2.5 Удаление фона
- Несколько моделей: быстрая, точная (волосы), для товаров, для людей.
- Ручная доработка кистью "стереть / вернуть".
- Экспорт: PNG/WebP с прозрачностью, цвет, градиент, своя картинка, тень, контур.
- Пакетная обработка (сотни фото товаров).
- Позже: видео и анимация без фона.

### 2.6 GIF-студия
- Из картинок: порядок кадров перетаскиванием, задержка на каждый кадр.
- Из видео: выбор отрезка, fps, размер.
- Редактор: обрезка, реверс, "пинг-понг", смена скорости, текст и стикеры.
- Оптимизация до целевого размера (качественная палитра: gifski или palettegen/paletteuse).
- Экспорт: GIF, анимированный WebP, APNG. Обратно: GIF → кадры.
- Прозрачная анимация (удаление фона у всех кадров).

### 2.7 Цепочки действий (пайплайны)
Например: убрать фон → уменьшить до 512 px → WebP → переименовать по шаблону. Сохраняются как пресеты и применяются к папкам.

### 2.8 Интеграция в Windows (то, что даёт приложению "родной" вид)
- Пункт **"Конвертировать…"** в контекстном меню проводника (правый клик по файлу/папке), поддержка нового меню Windows 11.
- **Следящие папки**: файл попал в папку, автоматически обработан по правилу.
- Перетаскивание файлов и папок, вставка из буфера (Ctrl+V), открытие через "Открыть с помощью".
- Уведомления Windows (Toast) по завершении, прогресс на иконке панели задач, Jump List.
- Автозапуск в трее (по желанию, для следящих папок).
- Тёмная/светлая тема по системной, стиль Fluent (Mica).
- Языки: русский и английский.

### 2.8.1 Ускорение на Windows
- Видео: NVENC (NVIDIA), Quick Sync (Intel), AMF (AMD) с автоопределением.
- Нейросети: ONNX Runtime + **DirectML**, работает на любой видеокарте (NVIDIA/AMD/Intel) без CUDA.
- Если GPU нет, откат на CPU.

### 2.9 ИИ-модули (докачиваются по желанию)
Апскейл (Real-ESRGAN), удаление шума, OCR (сканы → текст), субтитры из аудио (Whisper), удаление объектов с фото.

### 2.10 Приватность
"Работает полностью офлайн" как явный принцип. Оригиналы никогда не перезаписываются без согласия, есть отмена. Очистка метаданных одним переключателем.

## 3. Архитектура

```
UI (React + Fluent-стиль)
        │  IPC
Ядро приложения (Node/TS)
  ├─ Очередь задач (параллелизм, пауза, отмена, прогресс)
  ├─ Реестр конвертеров + граф форматов (поиск маршрута A → B)
  ├─ Пайплайны и пресеты, следящие папки
  └─ Менеджер модулей (докачка моделей и движков)
        │
Движки-плагины: FFmpeg · libvips · Pandoc · 7-Zip · ONNX Runtime (DirectML) · gifski
```

Каждый движок объявляет, что умеет ("вход: heic → выход: jpg"). Новый формат добавляется плагином. Если прямого пути нет, граф строит цепочку, например DOCX → PDF → PNG.

Хранение: настройки и пресеты в JSON в `%APPDATA%`, модели и движки в `%LOCALAPPDATA%`, временные файлы в `%TEMP%` с очисткой.

## 4. Технологический стек (под Windows)

**Рекомендация: Electron + React + TypeScript**
- Готовые привязки: sharp, onnxruntime-node (с DirectML), запуск FFmpeg как внешнего процесса.
- Самый широкий выбор библиотек, проще всего для старта.
- Минус: размер 150–300 МБ; решается тем, что тяжёлые модули докачиваются.

Альтернативы:
- **Tauri 2 (Rust + WebView2)**: меньше и быстрее, но нужен Rust.
- **.NET 8 + WinUI 3**: самый "родной" вид и интеграция, но придётся самому подбирать обёртки для FFmpeg/ONNX.

Выбор зависит от вашего языка. Если не определились, берём Electron.

Дополнительно:
- Сборка и установщик: electron-builder (NSIS `.exe`) + портативная версия; позже MSIX и публикация в Microsoft Store и winget.
- Автообновление: electron-updater.
- Подпись кода: сертификат (для отсутствия предупреждения SmartScreen), можно отложить на после запуска.
- Тесты: Vitest + набор эталонных файлов для каждого формата.

**Запланировано (пока не сделано): перейти с портативного exe на установщик.**
Сейчас `Morphio.exe` портативный и при каждом запуске распаковывается во временную папку,
поэтому окно появляется примерно через 20 секунд. Установщик (NSIS) один раз копирует
приложение на диск, и запуск станет быстрее. Как сделать: в `electron-builder.yml`
заменить цель `portable` на `nsis` (ярлыки в меню «Пуск» и на рабочем столе,
удаление через «Параметры → Приложения»). Портативную версию можно оставить второй целью.
Рядом нужно решить, где хранить модель нейросети: в `%APPDATA%\Morphio\models`
(её уже скачивает кнопка в приложении).

### v1.x и далее
Ручная доработка маски, пайплайны с редактором, ИИ-модули (апскейл, OCR, Whisper), видео без фона, PDF-инструменты (склейка, сжатие, подпись), CLI, плагины и обмен пресетами, ARM64.

## 6. Риски и юридическое

- **Лицензии**: FFmpeg (LGPL/GPL, зависит от сборки), Pandoc (GPL), LibreOffice (MPL). Для коммерции проверять каждый.
- **Модели фона**: U²-Net (Apache 2.0) и BiRefNet (MIT) можно; BRIA RMBG запрещена для коммерции без лицензии.
- **Кодеки**: H.264/HEVC/AAC имеют патентные ограничения; для личного и бесплатного использования обычно не проблема, для продажи нужен юрист.
- **SmartScreen**: неподписанный `.exe` будет пугать пользователей; план: подпись сертификатом.
- **Размер**: тяжёлые модели и движки докачиваются по требованию.
- **Качество фона** на волосах и прозрачных объектах: нужна ручная доработка.
- **Честные обещания**: показывать матрицу поддерживаемых форматов и расширять постепенно.

## 9. Детальный план v1.0 (продуманный)

Приложение публикуется на GitHub для бесплатного некоммерческого использования. Это определяет
выбор лицензии, обновлений и подписи (раздел 9.9). Принципы, которых держимся во всём:
**офлайн по умолчанию, никакой телеметрии, оригиналы не трогаем, любая загрузка из сети только с
согласием пользователя.**

### Порядок работ (почему именно так)

| Этап | Что | Зачем в этом порядке |
|---|---|---|
| A. Фундамент | установщик, хранилище настроек, журнал ошибок, лицензии и репозиторий, CI, e2e-тесты | всё остальное строится на этом; убирает 25-секундный запуск |
| B. Язык | инфраструктура RU/EN (i18n) | пока строк мало, дешевле сразу писать новые экраны с ключами, а не переводить потом |
| C. Реестр форматов | один модуль «из чего во что можно» + таблицы и архивы | нужен и для «всё в одном» конвертера, и для всплывающего окна, и для проводника |
| D. Фоновый режим | значок в трее, следящие папки, меню проводника, **горячая клавиша с окном** | требует A (настройки, быстрый запуск) и C (реестр) |
| E. Документы | Pandoc-модуль, PDF, книги, слайдер «до/после» | самое тяжёлое, зависит от модульной загрузки |
| F. Релиз | автообновление, подпись, релиз 1.0 | после того как есть что выпускать |

### 9.1 Установщик (NSIS) вместо портативного exe
- `electron-builder.yml`: цель `nsis` + вторая цель `portable` (портативную версию оставляем для тех, кому нужно без установки).
- Настройки установщика: `oneClick: false`, `perMachine: false` (ставится в `%LOCALAPPDATA%\Programs\Morphio`, **права администратора не нужны**), выбор папки, ярлыки на рабочем столе и в меню «Пуск», русский язык установщика, показ лицензии, при удалении данные пользователя (`%APPDATA%\Morphio`, модели) не трогаем, но спрашиваем, удалить ли их.
- Имена файлов: `Morphio-Setup-<версия>.exe` и `Morphio-Portable-<версия>.exe`.
- Модель нейросети и модули (Pandoc и др.) в установщик не кладём: размер остаётся около 150 МБ, остальное докачивается кнопкой в приложении в `%APPDATA%\Morphio\models` и `...\modules`.
- Результат: запуск за 1–3 секунды вместо 25 (приложение не распаковывается каждый раз). Портативная версия остаётся медленной, это ограничение формата, в README это написано.
- `rebuild.bat` собирает обе версии; в репозитории те же сборки делает CI.

### 9.2 Запоминание настроек
- Один файл `%APPDATA%\Morphio\settings.json`, пишется из основного процесса (атомарная запись: во временный файл, потом переименование; запись не чаще раза в секунду; версия схемы + миграции).
- Что сохраняем: последняя вкладка, размер и положение окна; настройки каждой вкладки (формат, качество, размер, фон, цвета, порядок GIF, параметры видео/звука, пресеты цепочек, папка сохранения); язык и тема (системная/светлая/тёмная); горячая клавиша; правила следящих папок; галочки «закрывать в трей», «запускать с Windows», «проверять обновления».
- Чего **не** сохраняем: списки файлов и результаты (это рабочее состояние).
- Пресеты цепочек сейчас лежат в `localStorage`: один раз переносим в `settings.json` (и они переживают переустановку).
- Реализация: IPC `settings:get/patch`, в интерфейсе хук `usePersistentState(ключ, значение по умолчанию)`; приложение показывается после загрузки настроек (без «мигания»).
- Кнопка «Сбросить настройки» и «Открыть папку данных» на экране «Настройки».

### 9.3 Проверка собранного exe
- **Автоматически (я могу делать сам):** e2e-тесты через Playwright для Electron (`_electron.launch` запускает настоящее окно). Сценарии: каждая вкладка открывается; конвертация сгенерированной картинки; удаление однотонного фона; сборка GIF из трёх кадров; конвертация коротких видео и звука; проверка, что выходные файлы существуют и открываются. Запуск `npm run e2e` и в CI на каждый коммит. Это закрывает «по кнопкам в exe не кликал».
- **Вручную (только вы можете):** `TESTING.md`: чек-лист на реальных файлах: фото с iPhone (HEIC), большие фото, спрайт-листы с розовым и зелёным фоном, свой GIF, видео с телефона, песня с обложкой, русские имена файлов и пути с пробелами, диск не `C:`. По каждому пункту: «ожидаемо / что увидели».
- Позже в тестах: «золотые» эталонные файлы (маленькие, лежат в `tests/fixtures`), чтобы регрессии вроде розовой каймы ловились автоматически.

### 9.4 Журнал ошибок и «Сообщить о проблеме»
- Журнал: `%APPDATA%\Morphio\logs\morphio-ГГГГ-ММ-ДД.log`, хранится 7 дней или до 5 МБ. Пишем: версию, ошибки конвертации с хвостом stderr от FFmpeg, необработанные исключения основного процесса и окна (`uncaughtException`, `unhandledRejection`, `render-process-gone`, `window.onerror`).
- Приватность: из логов вырезаем имя пользователя (`C:\Users\<имя>` → `%USERPROFILE%`), содержимое файлов никогда не пишем; без отправки в сеть.
- Экран ошибки (React ErrorBoundary): «Что-то пошло не так»: кнопки «Перезагрузить окно» и «Сообщить о проблеме».
- Карточка файла с ошибкой: клик открывает подробности (полный текст, «скопировать»).
- «Сообщить о проблеме» (в «О программе» и в экране ошибки): открывает **новый Issue на GitHub** с заполненным шаблоном (версия, Windows, видеокарта, что делали, последние строки журнала). Если текст слишком длинный для адреса, копируется в буфер обмена с подсказкой «вставьте сюда».
- Кнопка «Открыть папку логов».

### 9.5 Документы, таблицы, книги, архивы

**Единый вход.** Новый реестр форматов (`src/main/registry.ts`): каждый движок объявляет «из каких расширений в какие умеет» и функцию `run`. Функция `getTargets(файлы)` возвращает доступные варианты. Её используют вкладка «Универсальный» (бросил любой файл, выбрал во что), окно по горячей клавише и меню проводника. Существующие вкладки остаются как «специалисты».

| Категория | Форматы | Чем делаем | Заметки |
|---|---|---|---|
| Таблицы и данные | CSV, TSV, XLSX, JSON, XML, YAML | `exceljs` (xlsx), `papaparse` (csv), `yaml`, `fast-xml-parser`; всё MIT/ISC, внутри приложения | определение кодировки CSV (Windows-1251 для русских файлов), разделитель `;` или `,`, XLSX с несколькими листами → по CSV на лист; JSON ↔ CSV для списка объектов |
| Архивы | ZIP, 7z, TAR, GZ; RAR только распаковка | `7za.exe` из `7zip-bin` (LGPL, около 1 МБ) | «распаковать», «запаковать в ZIP/7z» (уровень сжатия, пароль), архив → другой архив. **Защита:** запрет `../` в путях (zip-slip), лимиты на размер и число файлов (zip-bomb), ничего не запускаем |
| Текстовые документы | DOCX, ODT, RTF, HTML, MD, TXT, EPUB, FB2 | **Pandoc** (GPL-2.0+), отдельным модулем | модуль ~ 150 МБ докачивается кнопкой с проверкой контрольной суммы (как модель нейросети) |
| PDF (вывод) | DOCX/HTML/MD/TXT → PDF | Pandoc → HTML → `printToPDF` встроенного Chromium: **LaTeX не нужен** | если на компьютере установлен LibreOffice, используем его для DOC/DOCX/XLSX/PPTX → PDF (точнее вёрстка); определяется автоматически |
| PDF (инструменты) | PDF → текст, PDF → картинки, картинки → PDF, склеить, разделить | `pdfjs-dist` (Apache-2.0) для чтения и показа, `pdf-lib` (MIT) для сборки | честное предупреждение: из PDF в DOCX вёрстка не сохраняется, получится текст |
| Книги | EPUB ↔ DOCX/HTML/MD/TXT, FB2 ↔ EPUB | Pandoc | MOBI/AZW3: только если установлен Calibre (`ebook-convert`), иначе пункт серый с пояснением |

**Модули по требованию** (`ModuleManager`, обобщение загрузчика модели): манифест (название, версия, адрес на GitHub Releases, SHA-256, размер, лицензия), экран «Модули» с кнопкой «Скачать», прогрессом и удалением. Без согласия ничего не скачивается.

**Очерёдность внутри этапа:** (1) таблицы и архивы (чистый JS и 7za, быстро); (2) Pandoc-модуль и документы; (3) PDF-инструменты; (4) книги.

### 9.6 Меню проводника и следящие папки

**Пункт «Конвертировать в Morphio»**
- Windows 11 показывает такие пункты в классическом меню («Показать дополнительные параметры», `Shift+F10`). Новое компактное меню требует отдельного COM-компонента в пакете MSIX, это сильно усложняет, поэтому делаем классический: реестр `HKCU\Software\Classes\SystemFileAssociations\...\shell\Morphio` (на пользователя, без прав администратора).
- Пункты: «Конвертировать в Morphio…» (открывает окно по горячей клавише с этими файлами), позже подменю «В WebP / В JPG / В MP3 / Без фона».
- Включение: галочка в «Настройках» («Добавить в меню проводника»; пишет и убирает ключи, работает и для портативной версии) и автоматически при установке (`installer.nsh`).
- Проблема множественного выбора: Проводник запускает **отдельный процесс на каждый файл**. Решение: `app.requestSingleInstanceLock()` и сбор аргументов `second-instance` в окне 300 мс в один пакет.
- Аргументы командной строки: `Morphio.exe --quick <файлы>` (окно) и `Morphio.exe --convert --to webp <файлы>` (без окна, с уведомлением Windows).

**Следящие папки**
- Правило = папка + что делать (пресет цепочки для изображений или пресет видео/звука) + куда класть результат (по умолчанию подпапка `Morphio-out`, чтобы не зациклиться) + расширения.
- Реализация: `chokidar` (MIT) с ожиданием, пока файл дописан (размер не меняется ~1,5 с), очередь на тех же `JobQueue`, по одному файлу за раз, повтор при ошибке, исключение собственной папки результатов.
- Нужен фоновый режим: значок в трее, галочки «закрывать в трей» и «запускать с Windows» (`setLoginItemSettings`, запуск скрыто `--hidden`).
- Экран «Следящие папки»: список правил, пауза, последняя активность, счётчик обработанных файлов. Уведомление Windows после пачки: «Обработано 12 файлов, сэкономлено 84 МБ».
- Старые файлы в папке при добавлении правила не трогаем (есть кнопка «Обработать то, что уже лежит»).

### 9.7 Слайдер «до/после» (изображения и видео)
- Компонент `CompareSlider`: два изображения друг на друге с движком, общий масштаб и перемещение, подписи «Оригинал 4,2 МБ» и «Результат 0,9 МБ (−78%)».
- **Метрики:** PSNR и SSIM считаем в основном процессе по уменьшенным серым копиям (до 512 px, около 50 строк кода, без новых зависимостей). Выводим человеческим языком: «Потеря качества: незаметна / небольшая / заметная».
- Видео: слайдер времени выбирает момент, кадры оригинала и результата берём через FFmpeg (уже есть `videoPoster`); для точных чисел `ffmpeg -lavfi ssim`.
- Вход: кнопка «Сравнить» на готовой карточке (как «Править» у удаления фона).
- Файлы в окно отдаём через собственный протокол `morphio-file://` с белым списком (только входные и выходные файлы текущей сессии), а не через `file://`.
- Позже: живой предпросмотр размера до конвертации (кодируем первый файл с текущими настройками и показываем цифру).

Совпадает с лицензией сборки FFmpeg, нужна для программ подписи для открытого кода (SignPath), Microsoft Store и т. п. **Запретить коммерческое использование открытой лицензией нельзя**, это не совместимо с определением открытого ПО. **FFmpeg (GPL-3.0, сборка gyan.dev essentials 6.1.1).** Мы запускаем его как отдельную программу (не линкуем), поэтому код Morphio не обязан быть GPL. Что обязательно при распространении:
- положить лицензию FFmpeg (файл `ffmpeg.exe.LICENSE` уже в пакете) в установщик и в `THIRD_PARTY_NOTICES.txt`;

- честно указать, что это чужая программа, а не часть Morphio.
Если когда-нибудь понадобится ослабить: LGPL-сборка FFmpeg без x264/x265, тогда H.264 кодируется только видеокартой (NVENC/AMF/QSV) или другими кодеками. Для бесплатной публикации не нужно.

### 9.10 Горячая клавиша и всплывающее окно быстрой конвертации

**Идея.** Выделили файлы в Проводнике, нажали сочетание (по умолчанию `Ctrl+Alt+M`), поверх всего мгновенно появляется компактное окно (как Spotlight / PowerToys Run). В нём уже видны ваши файлы, нужно нажать одну кнопку или цифру, и результат появляется рядом. Окно само исчезает.

**Откуда берутся файлы (по убыванию удобства):**
1. **Выделение в Проводнике.** В момент нажатия определяем окно Проводника на переднем плане и читаем выделенные файлы через `Shell.Application` (небольшой скрипт PowerShell/COM, 200–400 мс, без нативных модулей).
2. **Буфер обмена:** файлы, скопированные в Проводнике (`Get-Clipboard -Format FileDropList`), или **картинка** (скриншот `Win+Shift+S`): можно сразу убрать фон, сжать, сохранить в PNG/JPG.
3. **Перетаскивание** на окно и вставка `Ctrl+V`.
4. Запуск из меню проводника или командной строки (`--quick <файлы>`).
Если ничего не нашлось, показывается пустая область «Перетащите файлы сюда».

**Что в окне (около 440×340, без рамки, поверх всех окон, закрывается по `Esc` или при потере фокуса, на Windows 11 с акриловым фоном):**
- сверху: превью файлов и подпись «3 файла · 12 МБ · изображения»;
- **умные кнопки по типу файлов** (последний выбор стоит первым):
  - изображения: WebP · JPG · PNG · AVIF · «без фона» · «уменьшить до 1600»;
  - видео: MP4 · GIF · MP3 (только звук) · «до 10 МБ (Discord)»;
  - звук: MP3 · M4A · WAV · FLAC;
  - документы: PDF · DOCX · TXT · MD (после этапа E); таблицы: CSV · XLSX · JSON; архивы: «распаковать» · ZIP · 7z;
  - смесь типов: кнопки сгруппированы по категориям, либо одна готовая цепочка на все;
- **шесть закрепляемых действий** с цифрами 1–6: «хоткей → 2» и готово, без мыши;
- переключатели «качество: мало / средне / лучшее» и «куда: рядом / в папку по умолчанию»;
- прогресс прямо в окне; в конце: «Готово · −62% · [Показать] [Открыть]» и уведомление Windows, окно закрывается через несколько секунд;
- ссылка «Больше настроек» открывает главное окно на нужной вкладке с теми же файлами.

**Как это устроено технически:**
- `globalShortcut.register()` в основном процессе. Если сочетание занято, регистрация вернёт отказ: показываем причину и просим выбрать другое; в «Настройках» поле «нажмите сочетание» с проверкой. Сочетания с клавишей Windows Electron регистрировать не умеет.
- Окно создаётся **заранее скрытым** (второй `BrowserWindow`, маленькая отдельная страница `quick.html` без тяжёлых компонентов), поэтому показывается мгновенно. Позиция: рядом с курсором или по центру сверху, на нужном мониторе (`screen.getCursorScreenPoint()`), не выходя за рабочую область.
- **Работает фоном:** значок в трее (меню «Открыть / Быстрая конвертация / Настройки / Выход»), «закрывать в трей», «запускать с Windows». Фоновый процесс занимает порядка 80–120 МБ памяти; всё это включается галочкой и по умолчанию выключено, пока пользователь не включит «Быстрое окно».
- **Один экземпляр** (`requestSingleInstanceLock`): горячая клавиша принадлежит запущенной копии, повторный запуск просто передаёт ей файлы.
- Конвертация идёт теми же модулями и очередями (`convertImage`, цепочки, удаление фона, `convertMedia`, GIF), поэтому ничего не дублируется. Действие окна = запись «id, название, категория, функция» из реестра форматов (этап C).
- Ограничения: окна с повышенными правами (запущенные от администратора) Проводник читать не даёт; если выделение прочитать не удалось, используется буфер обмена, затем пустое окно.
- Безопасность: окно работает только с локальными файлами, без сети.

**Этапность.** Нужны: хранилище настроек, трей и быстрый запуск (установщик), реестр форматов. MVP: хоткей + буфер/перетаскивание + изображения, видео, звук. Затем выделение в Проводнике, цифры 1–6, документы после этапа E.
