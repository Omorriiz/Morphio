# Security / Безопасность

Morphio works offline and sends nothing to the network. The only downloads are modules and models that you start
yourself with a button, checked by SHA-256.
Morphio работает офлайн и ничего не отправляет в сеть. Скачиваются только модули и модели по вашей кнопке, с проверкой SHA-256.

**Reporting a vulnerability / Как сообщить об уязвимости.** Please do not open a public issue.
Use *Security → Report a vulnerability* in the GitHub repository (private advisory).
Не создавайте публичный Issue: используйте *Security → Report a vulnerability* в репозитории (закрытое уведомление).

Supported: the latest release. / Поддерживается последняя версия.
