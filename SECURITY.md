# Security

## English

Morphio works offline and sends nothing to the network. The only downloads are modules and models that you start yourself with a button (checked by SHA-256) and, if you turn it on, update checks.

**Reporting a vulnerability.** Please do not open a public issue. Use *Security → Report a vulnerability* in the GitHub repository (a private advisory).

**Supported versions.** Only the latest release.

## Русский

Morphio работает офлайн и ничего не отправляет в сеть. Скачиваются только модули и модели по вашей кнопке (с проверкой SHA-256) и, если вы включите, проверка обновлений.

**Как сообщить об уязвимости.** Не создавайте публичный Issue. Используйте *Security → Report a vulnerability* в репозитории на GitHub (закрытое уведомление).

**Поддерживаемые версии.** Только последний релиз.
